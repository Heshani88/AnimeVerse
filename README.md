AnimeVerse

AnimeVerse is a responsive anime discovery website built using HTML, CSS, and JavaScript.

Features

- 🏠 Home page with featured anime
- 🔍 Search anime
- 🎭 Filter anime by genre
- 🎬 View anime details
- ❤️ Add anime to Favorites
- 💾 Save Favorites using LocalStorage
- 🎞️ Anime image slider
- ▶️ Official trailer links
- 📺 Official streaming links
- 📚 Episode listing
- 🔄 Previous / Next anime navigation
- 🌙 Dark Mode and Light Mode
- 📱 Responsive design for mobile and desktop

Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Visual Studio Code

Project Goals

The main goals of AnimeVerse are:

- Create a simple and attractive anime discovery website.
- Practice frontend web development skills.
- Implement interactive features using JavaScript.
- Practice responsive web design.
- Apply software testing concepts to a real-world project.
- Build a project that can be presented as part of a developer and QA portfolio.
